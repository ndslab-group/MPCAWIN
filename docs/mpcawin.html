 35            The statistical information extracted from the sliding window is the threshold used 
 36            to decide whether a batch is too dissimilar from the statistical distribution. The threshold is calculated as 
 37            np.mean(sliding_window)+coef_std*np.std(sliding_window).
 38
 39        detect_strategy: str (default='detector')
 40            This parameter is used to determine how to analyze the one-dimensional distribution, it is recommended to use a valid one-dimensional detector.
 41

 43            Size of alert sliding window.
 44
 45        alpha: float (default=0.5)
 46            This parameter is used if the detect strategy is 'alert_rate'.
 47            The percentage of times inside the alert sliding window that triggers drift detection if the threshold is exceeded.
 48            It is equivalent to the alpha parameter of many drift detectors and adjusts the sensitivity of the detector.
 49            A value near 0.0 makes the detector more sensitive to noise but potentially faster at detecting drift.
 50            A value near 1.0 makes the detector more robust to noise but delays drift detection.
 51
 52        detector: BaseDriftDetector (default=None)
 53            It is used if the detect strategy is 'detector'.
 54            A BaseDriftDetection of skmultiflow.drift_detection.base_drift_detector.
 55
 56        random_seed: int (default=20)
 57            A seed for the random operations.
 58            Set this value for reproducibility of experiments.
 59
 60        Notes
 61        -----
 62        More detail in Sec. 4.1 and Fig.6 of 'HOIDS: Concept Drift Aware Hybrid Online Intrusion Detection System' paper.
 63
 64        References
 65        ----------

119    def set_concept(self, input_value):
120        """ Set the input batch of data as a actual concpet
121
122        Transforms a input batch of data with Standard Scaler and PCA trained on it.
123        Extracts the vector of eigenvalues of the batch.
124        Resets the change detector parameters.
125
126        Parameters
127        ----------
128        input_value: {array-like, DataFrame} of shape (n_samples, n_features)
129            Internally, it will be converted to DataFrame=pd.DataFrame.
130            New batch of data the detector should compare with last concept.
131        """
132        self.reset()
133        concept = pd.DataFrame(input_value)
134        self.scaler = StandardScaler(copy=True)
135        self.pca = PCA(copy=True)
136        self.scaler.fit(X=concept)
137        scaler_concept = self.scaler.transform(X=concept)
138        self.pca.fit(X=scaler_concept)
139        self.actual_transform_concept = self.pca.transform(X=scaler_concept)
140        self.actual_concept_eigenvalues = self.pca.explained_variance_

142    def add_element_and_detected_change(self, input_value):
143        """ Add a new batch of data and get detected change
144
145        Transforms a new batch of data with Standard Scaler and PCA trained on the last batch of data set as the current concept.
146        Extracts the vector of eigenvalues of the new batch and calculates the angle in degrees between 
147        the vector of eigenvalues of the new batch and that of the last concept.
148        Applies Statistical Hypothesis Test:
149         (1) calculates the threshold from the sliding window values;
150         (2) check whether or not the new angle exceeds the threshold;
151         (3) add 0 if the new angle does not exceed the threshold, add 1 if the new angle exceeds the threshold 
152         to the alert sliding window if the detect_strategy is 'alert_rate' otherwise to the detector.
153         (4) detect drift based on the alpha value if if the detect_strategy is 'alert_rate' otherwise based on the detector test.
154        Add the new angle to the sliding window if does not exceed the threshold.
155
156        Parameters
157        ----------
158        input_value: {array-like, DataFrame} of shape (n_samples, n_features)
159            Internally, it will be converted to DataFrame=pd.DataFrame.
160            New batch of data the detector should compare with last concept.
161
162        Returns
163        -------
164        bool
165            Whether or not a drift occurred
166
167        """
168        self.last_noise_angle = None
169        if self.actual_concept_eigenvalues is not None:
170            concept = pd.DataFrame(input_value)
171            scaler_new_concept = self.scaler.transform(concept)
172            self.pca.fit(scaler_new_concept)
173            v2 = self.pca.explained_variance_
174            ps = np.inner(self.actual_concept_eigenvalues, v2)
175            v1_norm = np.linalg.norm(self.actual_concept_eigenvalues)
176            v2_norm = np.linalg.norm(v2)
177            a = ps / (v1_norm * v2_norm)
178            angle = math.degrees(math.acos(a))
179            self.last_angle = round(angle,2)
180            if self.threshold is not None:
181                result = int(self.last_angle>self.threshold)
182                if self.detect_strategy == 'alert_rate':
183                    if self.alert_window.full():
184                        self.alert_window.get()
185                        self.alert_window.put(result)
186                        if list(self.alert_window.queue).count(1)>=math.ceil(self.alert_window.qsize()*self.alpha):
187                            self.set_concept(input_value)
188                            return True
189                    else:
190                        self.alert_window.put(result)
191                else:
192                    self.detector.add_element(result)
193                    if self.detector.detected_change():
194                        self.set_concept(input_value)
195                        return True
196                if result==0:
197                    if self.window.full():
198                        self.window.get()
199                        self.window.put(self.last_angle)
200                    else:
201                        self.window.put(self.last_angle)
202                    self.threshold = round(np.mean(self.window.queue)+self.coef_std*np.std(self.window.queue),2)
203                else:
204                    self.last_noise_angle = self.last_angle
205            else:
206                self.window.put(self.last_angle)
207                if self.window.qsize()==self.min_window_size:
208                    self.threshold = round(np.mean(self.window.queue)+self.coef_std*np.std(self.window.queue),2)
209        else:
210            self.set_concept(input_value)
211        return False

Parameters

max_window_size: int (default=10) Max size of sliding window to extract the statistical information of the measure of dissimilarity.

alert_window_size: int (default=20) Size of alert sliding window.

alpha: float (default=0.5) This parameter is used if the detect strategy is 'alert_rate'. detector: BaseDriftDetector (default=None) It is used if the detect strategy is 'detector'. A BaseDriftDetection of skmultiflow.drift_detection.base_drift_detector.

random_seed: int (default=20) A seed for the random operations. Set this value for reproducibility of experiments.
