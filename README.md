# MPACWIN
This repository contains the implementation of **MPCAWIN** from **HOIDS: Concept Drift Aware Hybrid Online Intrusion Detection System**.

## Overview
**MPCAWIN** is an unsupervised multi-dimensional concept drift detection method (MPCAWIN) based on the statistical distribution of input features, which requires no ground-truth labels during the detection phase and is therefore more practical than error-rate-based detectors in scenarios where timely annotation is infeasible. MPCAWIN also enhances robustness to noise and handles multiple types of drift.

For the complete documentation: https://ndslab-group.github.io/MPCAWIN

More detail in Sec. 4.1 and Fig.6 of 'HOIDS: Concept Drift Aware Hybrid Online Intrusion Detection System' paper.
